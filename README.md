## 👨‍💻 About Me

Hi! I'm **[Mohammad Ismail Hossain](https://github.com/ismailhossain-dev)**, a passionate **Full Stack Developer** focused on building modern, scalable, and user-friendly web applications.

I enjoy turning ideas into real-world digital solutions by combining clean frontend experiences with reliable backend systems. I work mainly with the **MERN Stack, Next.js, TypeScript, Prisma, and PostgreSQL**, while continuously exploring modern tools and best practices in web development.

### 🚀 What I Do

- 💻 Build **modern, responsive, and user-friendly web applications**
- ⚛️ Develop frontend applications using **React.js, Next.js, TypeScript, Redux & React Query**
- ⚙️ Build backend systems and **RESTful APIs** with **Node.js & Express.js**
- 🗄️ Work with **MongoDB, PostgreSQL, Prisma & Mongoose**
- 🔐 Implement **authentication, authorization, JWT & protected routes**
- 🧩 Follow **clean architecture, reusable code, and scalable project structure**
- 🎨 Create clean and interactive UI with **Tailwind CSS, Figma & Framer Motion**
- 🛠️ Use **Git, GitHub, VS Code & Postman** in my development workflow

### 🌱 Currently Learning

I'm continuously improving my skills by working on real-world projects, solving complex problems, and exploring modern technologies—currently focusing more deeply on **Prisma, PostgreSQL, TypeScript, backend architecture, and scalable application development**.

### 🎯 My Goal

My goal is to become a highly skilled **Full Stack Developer** capable of building reliable, scalable, and impactful software while continuously learning, improving, and solving real-world problems.
